So funktioniert die App

Start
Zeigt, wie viel Geld andere dir schulden und wie viel du anderen schuldest.
Darlehen
Ein Darlehen heißt: Eine Person gibt einer anderen Geld. Das Geld wird in Raten zurückgezahlt. 1 Rate = 1 Zahlung pro Monat.
Anfragen
Jemand bittet eine Gruppe um Geld. Andere machen ein Angebot. Wird das Angebot angenommen, entsteht ein Darlehen.
Personen
Alle Menschen in deinem Kreis. Zuverlässigkeit zeigt, wie pünktlich jemand bisher zurückgezahlt hat.
Verlauf
Eine Liste von allem, was passiert ist.
Farben
Grün = Geld kommt zu dir. Rot = Geld geht von dir weg oder etwas ist zu spät.
